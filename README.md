# Website Xuân Giáp Media

Website sử dụng bảng màu đen, trắng và các cấp xám trung tính. Toàn bộ giao diện dùng font Montserrat với phân cấp rõ ràng giữa tiêu đề, nội dung, chú thích và nút bấm.

Giao diện mobile đã được tối ưu cho màn hình nhỏ: menu toàn màn hình dễ thao tác, hero gọn hơn, danh mục tài nguyên vuốt ngang, vùng bấm tối thiểu 44px và form không bị phóng to ngoài ý muốn trên iPhone.

Website gồm ba file chính:

- index.html: nội dung và bố cục trang.
- style.css: màu sắc, font, hiệu ứng và giao diện mobile.
- script.js: menu, hiệu ứng, bộ lọc, tìm kiếm, form liên hệ và danh sách sản phẩm.

## Cách mở trên máy

Mở thư mục bằng VS Code, sau đó mở file index.html bằng Live Server hoặc trình duyệt.

## Các tính năng & chuyên mục nổi bật

- **Dự án nổi bật**: Video - Film (Brand Film, Wedding, Music Video, Event Recap, TVC, Phim tài liệu), Ảnh (Kỷ yếu Duy Hưng, Profile, Sản phẩm, Kiến trúc), Social Media (Reels, Podcast, Campaign). Hỗ trợ xem thêm / thu gọn linh hoạt.
- **Tài nguyên Edit Video & Ảnh**: Preset, LUT CapCut, Hiệu ứng Film, Background Colorful, Lưới video dọc, SFX & Nhạc Epidemic.
- **Trang chi tiết**: Kỷ yếu Duy Hưng, Brand Film, Wedding Film, Music Video, Event Recap.
- **Form liên hệ**: Tích hợp gửi email tự động và liên hệ Zalo / Hotline.
